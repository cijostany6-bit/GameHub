One command rebuilds all of this

The pages you are reading are generated from the Markdown in the repository — no static-site framework, no npm packages, no network. Running the script again reproduces them byte for byte, and the same content becomes a printable A4 guide.

CommandWhat it does
node scripts/build-learn.jsRegenerate this site and the print guide
./scripts/build-pdf.shRebuild everything and render learn/gamehub-guide.pdf

GameHub /learn — generated from README.md and docs/*.md by scripts/build-learn.js. Fonts are self-hosted (OFL); this site makes no third-party requests.
